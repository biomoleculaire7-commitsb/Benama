# منصة متوسطة الشهيد بن نعمة مصطفى — دليل النشر على Render

تطبيق Flask حقيقي (بدل نموذج HTML التجريبي) — دخول بالرقم التعريف الوطني/الوظيفي، إرسال واستلام وثائق حقيقية بين الأستاذ والتلميذ، وتحميل قوائم الأقسام.

## الطريقة الأسهل: النشر عبر GitHub (موصى بها)

1. أنشئ حساباً على [github.com](https://github.com) إن لم يكن لديك واحد.
2. أنشئ مستودعاً (Repository) جديداً فارغاً، مثلاً باسم `benama-platform`.
3. ارفع كل ملفات هذا المجلد إليه (يمكن بالسحب والإفلات مباشرة من واجهة GitHub في المتصفح: "Add file" → "Upload files").
4. اذهب إلى [render.com](https://render.com) وسجّل دخولاً (يمكن عبر حساب GitHub مباشرة).
5. اضغط **New +** → **Web Service**.
6. اختر المستودع الذي رفعته للتو.
7. Render سيكتشف تلقائياً ملف `render.yaml` ويملأ الإعدادات (Build: `pip install -r requirements.txt`, Start: `gunicorn app:app`). إن لم يكتشفه تلقائياً، أدخلها يدوياً.
8. اختر الخطة **Free**، ثم اضغط **Create Web Service**.
9. انتظر 2-3 دقائق حتى ينتهي البناء — سيعطيك Render رابطاً مباشراً مثل `https://benama-platform.onrender.com`.

## بعد النشر

- افتح الرابط في أي متصفح (كمبيوتر أو جوال) — لا حاجة لأي إعدادات إضافية.
- تسجيل الدخول والوثائق ستعمل بشكل طبيعي تماماً (بلا القيود التي واجهتها سابقاً داخل نافذة المعاينة).

## ملاحظة مهمة: تخزين الملفات على الخطة المجانية

الخطة المجانية في Render تُعيد تشغيل الخادم من حين لآخر (بعد فترة خمول)، مما **يمسح الملفات المرفوعة والوثائق المُرسلة** المخزَّنة محلياً على القرص (`uploads/` و`data/documents.json`). هذا مقبول تماماً لمرحلة التجربة والعرض، لكن للاستخدام الفعلي طويل الأمد، ستحتاجون لاحقاً:
- الترقية لخطة مدفوعة بقرص دائم (Persistent Disk)، أو
- ربط قاعدة بيانات ومخزن ملفات خارجيين (مثل PostgreSQL + Cloudinary/S3) — يمكنني المساعدة في ذلك عند الحاجة.

## هيكل المشروع

```
app.py                  # الخادم (Flask) — كل نقاط النهاية API
templates/index.html    # الواجهة (تتواصل مع الخادم عبر fetch)
data/school_data.json   # قاعدة بيانات التلاميذ والأساتذة الحقيقية (281 تلميذاً، 42 موظفاً)
uploads/                # الملفات المرفوعة من الأساتذة (تُنشأ تلقائياً)
requirements.txt        # مكتبات Python المطلوبة
Procfile / render.yaml  # إعدادات التشغيل على Render
```
